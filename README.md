### 👨‍💻 About This Project

This is my personal portfolio built to showcase my projects, technical skills, and journey as a **Full Stack Developer**. Designed with a clean, dark-mode **Bento Grid** aesthetic, focused on speed, responsiveness, and zero-bloat architecture.

- 🌐 **Live Demo:** [seu-usuario.github.io](https://github.io)
- ⚡ **Performance:** Pure HTML5, Tailwind CSS, and Vanilla JS — zero build steps, instant load.
- 📱 **Responsive:** Mobile-first layout adapted for all screen sizes.

### 🚀 Running Locally

Want to run or customize this template locally? Just clone the repository and open `index.html`:

```bash
# Clone this repository
git clone https://github.com

# Navigate to the folder
cd SEU-REPOSITORIO

# Open index.html in your browser (or use VS Code Live Server)
```
