### 👋 Sobre mim

Prazer, sou o **Gabriel** — por aqui você me encontra como **`0xgabriel`**.

Comecei na programação desmontando coisas por curiosidade até entender como elas realmente funcionam por trás dos panos. Hoje atuo como desenvolvedor **Full-Stack** com foco forte em **Cibersegurança**, tirando projetos do zero até a produção.

Meu jeito de trabalhar é direto: prefiro código limpo a complexidade desnecessária, levo segurança de banco de dados a sério e gosto de ajustar cada detalhe até a aplicação abrir instantaneamente — de preferência em um bom **dark mode**.
