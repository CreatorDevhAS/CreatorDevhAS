### 👨‍💻 Sobre mim

Sou desenvolvedor **Full-Stack** e entusiasta de **Cibersegurança** (`0xgabriel`). Curto pegar uma ideia do zero, desenhar a arquitetura inteira e entregar algo rápido, blindado e com aquela interface dark mode limpa de usar.

Não sou fã de código enrolado — gosto de resolver problema real, travar banco de dados contra brechas e espremer cada milissegundo de performance (tanto nas aplicações quanto no FPS dos jogos).
