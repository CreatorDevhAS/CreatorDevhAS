### Sobre mim

E aí, sou o **Gabriel**, mas pela internet uso **`0xgabriel`**.

Trabalho com desenvolvimento **Full-Stack** e **Cibersegurança**. Gosto de tirar projetos do zero e colocar em produção, cuidando desde a interface até a estrutura do banco e a proteção do servidor.

Não sou muito fã de código enrolado ou site pesado. Se é pra construir algo, prefiro que abra rápido, fique seguro e tenha um dark mode decente.
